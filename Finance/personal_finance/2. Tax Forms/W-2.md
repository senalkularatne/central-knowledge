# W-2

## What is it?

- Form your employer gives you summarizing your earnings and tax withholdings for the year
- You need it to file your tax return

## Key Boxes

| Box | Description |
|-----|-------------|
| 1 | Wages, tips, other compensation (federal taxable income) |
| 2 | Federal income tax withheld |
| 3 | Social Security wages |
| 4 | Social Security tax withheld |
| 5 | Medicare wages |
| 6 | Medicare tax withheld |
| 12 | Various codes (e.g., C = GTL, D = 401k, DD = health coverage cost) |
| 15-17 | State wages and state income tax withheld |

## How Box 1 is calculated

```
Gross wages
+ Taxable benefits (e.g., GTL over $50k)
- Pre-tax deductions (health insurance, 401k, HSA, etc.)
= W-2 Box 1
```
