# Real Assets

This branch covers physical real assets: things such as land, buildings, and raw materials. They can have value because they can be used, occupied, consumed, or sold.

Owning a physical asset is different from owning a financial claim connected to it. For example, owning a building is not the same as owning shares in a company that owns buildings.
