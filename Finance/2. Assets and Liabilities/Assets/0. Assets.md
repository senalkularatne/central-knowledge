# Assets

## What is an Asset?

- An asset is anything of value that a person or entity owns.
- Assets are sorted by where the value comes from:
  - Financial Assets: value comes from a legal claim, such as ownership of a company or a right to be repaid.
  - Real Assets: value comes from the physical thing itself, such as land, buildings, or commodities.

## Securities are a subset of Assets

- Every security is an asset. Not every asset is a security.
- A security is a tradable financial asset, so it lives inside Financial Assets.
