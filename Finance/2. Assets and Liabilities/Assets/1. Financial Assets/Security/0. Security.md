# Security

## What is a Security?

- A security is a tradable financial asset. 
- To be a security, an asset must belong to at least one of these independent categories:
  - A share of ownership in a company (a Stock)
  - A loan made to a government or corporation (a Bond)
  - A financial contract based on an underlying asset (an Option)
